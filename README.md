# Debian Terminal Simulator 更新说明

## 更新概览

本次更新调整了软件中心菜单、模拟终端命令处理、HTML 预览权限和 AI API Key 安全提示等内容。

## 功能与问题修复

### 1. 软件中心菜单

- 调整双平台下载链接的菜单流程，进入平台选择菜单后会正确处理后续操作。
- 对只有一个可用下载链接或没有可用链接的软件条目，改进了返回软件列表的处理。
- 清理了相关代码中的无效自赋值逻辑。

### 2. `rm` 命令参数识别

- 改进递归删除参数的识别逻辑。
- 支持 `-r`、`-rf`、`-fr`、`-Rf` 等参数组合。

**说明：** 本项目提供的是网页模拟终端，命令操作仅作用于模拟环境，不会直接修改设备或真实 Linux 系统中的文件。

### 3. `cp` 和 `mv` 命令

- 支持将文件复制或移动到已存在的目录，并保留源文件名。
- 增加对源文件、目标父目录、目标目录及同文件移动等情况的检查。
- 暂不支持目录递归复制或移动；遇到此类操作时会显示相应提示。

### 4. `grep` 命令

- 增加 `-i`（忽略大小写）和 `-n`（显示行号）选项。
- 支持 `-in`、`-ni` 等组合写法。
- 支持搜索多个文件；搜索多个文件时会显示文件名前缀。

### 5. `ls -l` 输出

- 文件大小按 UTF-8 编码后的字节数估算。
- 目录大小使用模拟值 `4096`。
- 输出时间使用固定的模拟时间 `Oct 27 12:00`。

### 6. HTML 预览与 API Key 安全提示

- 收紧 HTML 预览 iframe 的 sandbox 权限，移除了 `allow-forms`。
- 明确说明公开网页中的浏览器 `localStorage` 内容可能被访问者通过开发者工具查看。
- 浏览器直接调用第三方 API 时，API Key 可能暴露给访问者。
- 面向公开部署的项目，建议通过服务端代理处理 API 请求，并避免在公开页面中填写重要或长期使用的密钥。

### 7. 代码整理

- 将自定义 `prompt()` 函数重命名为 `renderPrompt()`，并同步更新相关调用，减少与浏览器内置 `prompt()` 函数发生名称混淆的可能。

## 当前已知限制

以下功能仍有待后续改进：

- **天气国家或地区匹配：** 现有匹配逻辑对部分国家或地区的识别仍可能不准确。
- **`exit` 命令：** 当前主要显示退出提示，不会真正结束模拟终端会话。
- **目录递归操作：** `cp` 和 `mv` 暂不支持目录递归复制或移动。

以上限制已明确列出，后续可在补充测试后继续改进。

## 检查与测试

- 已提取 JavaScript 代码并执行 `node --check`，语法检查通过。
- 尚未完成所有功能的浏览器端回归测试，因此语法检查通过不代表所有功能均已在不同浏览器和设备上验证。

建议后续重点测试：

1. 软件中心单链接与双链接条目的菜单流程。
2. `rm -r`、`rm -rf` 等模拟命令的参数识别。
3. `cp`、`mv` 对已存在目录和目标文件的处理。
4. `grep -in`、多文件搜索和行号显示。
5. HTML 预览及 AI 设置提示的显示效果。

## 项目说明

Debian Terminal Simulator 是一个网页终端模拟项目。模拟终端中的命令和文件操作仅用于演示网页内部的模拟状态，不等同于真实 Debian 系统，也不保证完整复现所有 Linux 命令的行为。
